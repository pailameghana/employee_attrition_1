About the Explainable Prediction Model

What does this application do?

It uses machine learning to estimate whether an employee may be at risk of leaving the organization and explains why.

How does it work?

1. HR enters employee information.
2. Machine learning model analyzes employee characteristics.
3. System predicts attrition probability percentage.
4. SHAP engine explains major factors behind the prediction.
5. HR uses explanations as decision-support information.

Technologies Used

Python Pandas & NumPy Scikit-learn Stacking Ensemble Learning SHAP Explainability Engine FastAPI Backend Vanilla HTML/CSS/JavaScript
Responsible Use Notice

This application is designed to support HR analysis and workforce planning. Predictions are estimates based on available employee data and should not be used as the sole basis for employment decisions. HR professionals should consider employee context and other relevant qualitative information.
